# Movie Industry Data Analysis Using Microsoft Excel

## Project Overview
This project uses Microsoft Excel to explore movie-industry data and present findings through data analysis and visualisation.

## Project Objectives
- Analyse movie budgets and revenue.
- Explore profitability and return on investment (ROI).
- Compare movie performance across studios and release years.
- Present important metrics using an Excel dashboard.

## Tools Used
- Microsoft Excel
- Data cleaning and validation
- Excel formulas and summary tables
- Charts and dashboard visualisation

## Project Files
- Excel workbook containing the dashboard and supporting analysis.

## Key Learning Outcomes
- Practised organising and validating data.
- Improved spreadsheet-based analytical skills.
- Learned to present data using charts and summary metrics.
